# Green Leaf Counseling — Static Website

This is a static HTML website for Green Leaf Counseling NYC.
Files: index.html, services.html, groups.html, contact.html, plus images.
No build step — files are served directly as HTML.

The site is live at https://zl2799--greenleaf-web.modal.run/
After making changes, the user can click "Preview site" in the chat UI to see updates.
To deploy to production (GitHub Pages), the user clicks "Deploy" in the UI.

## Rules
- Edit HTML files directly. No build tools needed.
- After making changes, always run: git add -A && git commit -m "<descriptive message>"
- Do not modify CLAUDE.md.
- Keep changes minimal and focused on what was asked.
